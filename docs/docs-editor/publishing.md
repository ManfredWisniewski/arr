# Publishing content

Content on an ARR site is written outside the CMS and **synced** in —
every synced page arrives as a **draft**. Nothing goes live without a
human confirming it.

## The lifecycle

```text
content written in the content repository
→ synced to the site as a draft
→ reviewed by an editor
→ published (one page at a time)
```

## What this means for you

- A page you have not yet published is invisible to visitors — only
  logged-in editors can see drafts.
- Publishing is always **per page**: you confirm exactly the document in
  front of you, never a batch.
- If synced content was edited manually in the admin, the next sync
  overwrites those edits — the content repository is the source of truth.

## Media

Images and files are synced together with the pages that use them and are
live immediately — media has no draft state.
