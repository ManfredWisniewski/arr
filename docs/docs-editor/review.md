# The review flow

## Draft banner

When you are logged in and view a page whose latest version is a draft, a
banner at the top tells you it is **not live** and offers a **Publish**
action. Confirm it and the page goes live immediately — the banner
disappears on the next view.

Anonymous visitors never see the banner or any draft content.

## `/review` — the pending index

`/review` lists every document whose latest version is unpublished across
pages, posts and structures, with a link to each draft view:

1. Open `/review` to see what is pending.
2. Open an item, check it as the public will see it, confirm with
   **Publish**.
3. The flow automatically advances to the next pending document — or back
   to `/review` when nothing remains.

A document confirmed anywhere (admin, banner, review flow) drops out of
the list on the next load.
