# Redaktions-Dokumentation

Alles, was du brauchst, um Inhalte auf einer ARR-Website zu veröffentlichen
und zu prüfen. Keine Repository- oder Admin-Kenntnisse nötig — nur ein
`editor`-Konto.

- [Inhalte veröffentlichen](./publishing.md) — wie Inhalte auf die Website
  kommen und warum alles als Entwurf beginnt.
- [Der Review-Ablauf](./review.md) — der Entwurfs-Banner und der
  `/review`-Index zum Abarbeiten ausstehender Seiten.
- [Rollen](./roles.md) — wer was darf (`editor` vs. `content-bot`).
