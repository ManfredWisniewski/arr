# Inhalte veröffentlichen

Inhalte einer ARR-Website werden außerhalb des CMS geschrieben und
**synchronisiert** — jede synchronisierte Seite kommt als **Entwurf** an.
Nichts geht live, ohne dass ein Mensch es bestätigt.

## Der Lebenszyklus

```text
Inhalt wird im Content-Repository geschrieben
→ als Entwurf auf die Website synchronisiert
→ von einer Redakteurin/einem Redakteur geprüft
→ veröffentlicht (Seite für Seite)
```

## Was das für dich bedeutet

- Eine Seite, die du noch nicht veröffentlicht hast, ist für Besucher
  unsichtbar — nur angemeldete Redakteure sehen Entwürfe.
- Veröffentlicht wird immer **pro Seite**: du bestätigst genau das Dokument
  vor dir, niemals einen Stapel.
- Wurden synchronisierte Inhalte manuell im Admin geändert, überschreibt
  die nächste Synchronisation diese Änderungen — das Content-Repository
  ist die Quelle der Wahrheit.

## Medien

Bilder und Dateien werden zusammen mit den Seiten synchronisiert, die sie
verwenden, und sind sofort live — Medien haben keinen Entwurfsstatus.
