# Privacy

Demo privacy page. The demo site stores no visitor data: no tracking,
no analytics cookies, no embedded third-party scripts. Applications
submitted through the jobs demo store their data in the local test
database only.

Server logs on the test host are used for debugging and are reset when
the vhost is reprovisioned.
