# Contact

This is the demo contact page. On the real site this template renders
the contact block — here it shows that the `contact` template resolves
through the registry like any other named template.

- Demo platform: arr (Payload CMS + Next.js)
- Content source: `tests/assets/demo-content` in the arr repository
- Test host: the development vhost, reachable on the LAN

For data handling see the [privacy page](/contact/privacy).
