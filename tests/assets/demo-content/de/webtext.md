# arr Demo

Eine Demo-Site, die in die arr-Payload-Plattform gepusht wurde. Alle
Inhalte hier sind Attrappen im w1t.org-Format — gleiche Struktur,
gleiches Frontmatter, aber eigener Text.

Die Beiträge beschreiben, wie die Plattform selbst funktioniert: ein
abgeleitetes Read Model, das per REST-Push befüllt wird, Markdown, das
beim Validieren zu Lexical wird, Entwürfe hinter einer Editor-Freigabe
und eine Plugin-Architektur, die Features entfernbar hält.
