# arr Demo

A demo site pushed into the arr Payload platform. Every page here is
mockup content in the w1t.org format — same structure, same frontmatter,
original text.

<witSpace size="800" maxTilt="38" authors="dominik@3:near,leon@5:near,lukas@6:near,claudia@9:near,melkador@12:near,manfred@20:near,trurl@0:far,pirx@14:far" />

The posts document how the platform itself works: a derived read model
fed by REST pushes, markdown converted to Lexical on validate, drafts
behind an editor gate, and a plugin architecture that keeps features
removable.
